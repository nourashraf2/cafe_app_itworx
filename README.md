## 📝 Overview

The Cafe Ordering App is a full-stack web application that allows users to register, browse a dynamic menu, add items to a cart, and place online orders. It also includes an admin panel with full control over menu items and user management.

---

## 🚀 Features

### 👤 User Functionality
- 🔐 Register and Login using JWT authentication
- 📋 View available menu items
- 🛒 Add items to a shopping cart
- ✅ Place orders securely

### 🛠️ Admin Functionality
- ➕ Add/Edit/Delete menu items
- 👮 Manage users and admins
- 🚫 Block or unblock users and other admins
